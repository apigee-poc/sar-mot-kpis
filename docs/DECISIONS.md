(4) The debug masks also cover `verifyapikey.VA-VerifyApiKey.client_id` (the API key, also the SpikeArrest/Quota identifier), with both case forms of the three headers because the docs do not say whether matching is case-sensitive (VERIFY in a dev debug session). | 2026-11-11 (P5, Tasks A and B and their reviews).
